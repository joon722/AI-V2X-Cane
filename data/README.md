# data/ — 현장 실험 원본 기록

이 폴더는 **실제 도로에서 수집한 원본 로그**입니다. 가공하지 않은 raw 데이터라 그대로 보면 숫자 나열이지만,
**무엇을 담고 있고 무엇을 보여주는지**를 아래에 정리했습니다.

> 📊 **이 데이터로 만든 시각화 결과는 [docs/현장 결과](../docs/field-results.ko.md)에서 한눈에 볼 수 있습니다.**
> (실측 접근 타임라인 + 10만 건 거리–위험 분포)

---

## 파일 종류 (공통)

| 파일 | 내용 |
| --- | --- |
| `risk_tx_YYYYMMDD_HHMMSS.csv` | **Jetson이 그 순간 내린 판정 결과.** 거리·TTC·접근속도·위험등급·GPS 유효·모델 확률까지 한 행에. 위 결과 페이지 차트의 원본. |
| `raw_YYYYMMDD_HHMMSS.log` | RSU 브리지가 받은 **원본 시리얼 스트림**(JSON 라인). 지팡이·차량·UWB 패킷 원본. |
| `차량_값기록.csv` · `지팡이_값기록.csv` | 각 노드가 **자체 기록한 원본 값**(듀얼 시리얼 동시 수집). |

## 다시 그리기


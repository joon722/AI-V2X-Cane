# 야외 실측 데이터 (2026-08-12 저녁 ~ 08-13 오전)

상도동 야외 실험. 지팡이 고정 + RC 차량 왕복/접근. 젯슨(RSU 엔진 step8)이 기록한
판정 CSV(`risk_tx_*.csv`)와 원시 시리얼 로그(`raw_*.log.gz`, gzip).

- 8/12 = **수정 전** (TTC 상한 없음, "10m 이내 30점" 규칙으로 오경보 93%)
- 8/13 = **수정 후** (TTC 30초 상한 + 안전하한 2.0초 배포, 지팡이 RSU 수신 복구)

노드측 기록(지팡이/차량 UDP 텔레메트리)은 GCS `hanium-ssu-kpc-records/듀얼시리얼기록/`에 별도 보관.

## 파일 형식

- `risk_tx_*.csv`: 판정 1행 = 1판정. `pc_time`은 유닉스 epoch(KST 벽시계와 일치).
  주요 컬럼: `effective_level`(송신 레벨), `rule_level`/`rule_reason`(규칙 판정,
  8/13부터 `ttc_capped` 등장), `distance_m`/`closing_mps`/`ttc_s`, `cane_node_risk`/
  `veh_node_risk`(노드가 방송한 최종위험 — 다운링크 반영 확인용), 양 노드 GPS 상태.
- `raw_*.log.gz`: `시각 RX/TX 원문` 형식. RX는 노드 업링크 JSON(위치·속도·heading_valid
  포함), TX는 젯슨 위험도 송신. 파일명 타임스탬프가 짝이 되는 CSV와 같음.
